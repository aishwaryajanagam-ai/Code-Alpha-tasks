# Iris Flower Classification

## Project Overview

This project classifies Iris flowers into three species using Machine Learning.

### Species

* Iris Setosa
* Iris Versicolor
* Iris Virginica

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Model Used

Random Forest Classifier

## Results

The model achieved high accuracy in classifying Iris flower species.
