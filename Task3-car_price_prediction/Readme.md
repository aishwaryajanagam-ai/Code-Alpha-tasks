# Car Price Prediction

A Machine Learning project that predicts the selling price of a car based on various features such as vehicle age, fuel type, transmission type, present price, and kilometers driven. This project demonstrates the application of regression techniques for real-world price prediction.

## Project Goal

The objective of this project is to build a machine learning model that can accurately estimate the selling price of a used car using historical vehicle data.

## Dataset Features

The dataset contains information such as:

- Car Name
- Year
- Present Price
- Selling Price (Target Variable)
- Driven Kilometers
- Fuel Type
- Selling Type
- Transmission
- Owner

## Key Insights

- Present Price is one of the strongest predictors of selling price.
- Vehicle age significantly impacts resale value.
- Fuel type and transmission contribute to price variations.
- Random Forest Regressor provides strong predictive performance.
